1. Executive Summary

The Sahayog HR Management System is hosted in a high-efficiency, fully containerized production architecture deployed on Amazon Web Services (AWS). The system is provisioned via AWS CloudFormation and optimized for the AWS Free Tier, enabling zero operational hosting costs while delivering full HTTPS TLS encryption, automatic subdomain routing, persistent database backups, and high availability for both web users and the native Android mobile app.

5. Containerized Services Running on EC2

Caddy 2 Proxy (app-caddy-1)

Acts as the front-facing entry point. Terminates SSL/TLS with zero maintenance using automatic Let's Encrypt certificates. Serves the pre-compiled React frontend SPA directly from the /srv mount and proxies API requests to Gunicorn.

Django Backend (app-api-1)

Runs Django 4.2.16 with Gunicorn WSGI workers on Python 3.12-slim. Implements REST APIs, JWT authentication, soft-deletes, role-based access control, attendance rules, and automated payslip PDF generation.

PostgreSQL 16 (app-db-1)

Production database using PostgreSQL 16 Alpine. Data is persisted outside the container in Docker volume app_postgres_data, guaranteeing zero data loss across container rebuilds or reboots.

Persistent Volumes

• app_postgres_data: Relational database records.
• app_media_data: Uploaded documents & payslip PDFs.
• app_caddy_data: SSL certificates & OCSP state.
• app_caddy_config: Caddy dynamic runtime configs.

6. Strategic Free-Tier Design Choices

Why are we not using AWS RDS, AWS S3, or AWS Lambda?
Managed AWS services introduce monthly recurring costs (e.g. AWS RDS typically costs $15–$30/mo, S3 incurs request charges, and Route 53 incurs zone maintenance fees). By co-locating the database and reverse proxy in lightweight Docker containers on an encrypted EBS volume, Sahayog HR achieves 100% Free-Tier compliance ($0/mo) while maintaining production-grade reliability and security.
