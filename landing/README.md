# Sahayog HR landing site

This is a standalone static website. It has no build step or dependency on the desktop application.

To host it, publish the contents of this `landing` folder with any static host, such as GitHub Pages, Netlify, Vercel, or your web server's public directory.

The Windows and Android download buttons point to the corresponding file in the project's `latest` GitHub Release. The build workflows update those files after each successful build.

`https://github.com/sankiinikam/sahayog-hr/releases/latest`

Publish the `.exe` and `.apk` as Release assets in GitHub for the buttons to provide direct downloads.
